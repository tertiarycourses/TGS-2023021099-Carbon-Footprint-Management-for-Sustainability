# Activity 3: Find Hotspots in a Farm-to-Table Value Chain

**Real-use-case lens:** CP Foods-inspired teaching case  
**Source lens:** SAP customer spotlight and GHG Protocol  
**Objective:** Calculate a screening footprint, rank hotspots and propose a data-improvement plan.  
**Deliverable:** Calculated footprint, Pareto chart and hotspot recommendation

## Scenario

Orchid Foods produces chilled ready meals for Singapore retailers. Inspired by CP Foods’ farm-to-table footprint work, it wants a first screening of ingredients, factory energy, cold-chain logistics, packaging and waste. All figures are illustrative teaching data, not reported CP Foods results.

## Detailed procedure

1. Review the activity-data table and check every unit.
2. Match each row to the supplied illustrative emission factor.
3. Calculate tCO₂e for every source and retain the formula trail.
4. Classify each result by scope and value-chain stage.
5. Calculate total footprint and percentage contribution.
6. Rank sources and draw a Pareto chart.
7. Normalise the result per 1,000 meals and per S$1 million revenue.
8. Rate the top five sources by data quality and controllability.
9. Select two priority data improvements and assign owners.
10. Present a hotspot narrative that distinguishes calculation result from management judgement.

## Evidence checklist

- State the boundary, period, unit and source for every material figure.
- Separate calculated result, assumption and management judgement.
- Show formulas and retain intermediate values.
- Label company-linked figures as reported or illustrative.
- Record uncertainty, limitation and data-improvement actions.
- Ensure the final recommendation answers every scenario question.
