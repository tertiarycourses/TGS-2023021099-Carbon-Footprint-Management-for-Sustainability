# Activity 6: Prioritise a Reduction Portfolio

**Real-use-case lens:** WITTE Automotive-inspired teaching case  
**Source lens:** SAP customer spotlight, CarbonChain and IMD  
**Objective:** Combine MACC, weighted criteria, dependencies and budget constraints into a transparent portfolio.  
**Deliverable:** MACC, MCDA matrix, funded roadmap and decision record

## Scenario

A Singapore automotive-components supplier has six shortlisted initiatives and S$700,000 available in Wave 1. The case is inspired by public examples of enterprise footprint management; all decision data are illustrative.

## Detailed procedure

1. Check initiative boundaries and remove any overlapping savings.
2. Calculate lifetime tonnes avoided and lifetime net cost.
3. Calculate marginal abatement cost for each initiative.
4. Agree weights for carbon, NPV, feasibility, strategy and confidence.
5. Define 1–5 scoring anchors before scoring.
6. Score each initiative using the evidence supplied.
7. Run a sensitivity case that doubles the carbon-impact weight.
8. Map technology, data, procurement and infrastructure dependencies.
9. Select a Wave 1 portfolio within the S$700,000 cap.
10. Document funded, pilot, enable and defer decisions with reasons.

## Evidence checklist

- State the boundary, period, unit and source for every material figure.
- Separate calculated result, assumption and management judgement.
- Show formulas and retain intermediate values.
- Label company-linked figures as reported or illustrative.
- Record uncertainty, limitation and data-improvement actions.
- Ensure the final recommendation answers every scenario question.
